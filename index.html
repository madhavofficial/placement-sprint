Main Goal
Refresh the major concepts first, then spend the majority of the preparation time solving problems and developing pattern recognition under placement-style time pressure.
Key Strategy & Subject Priorities:
  • DSA (Heavy Focus): The majority of your preparation effort must be on DSA and solving problems.
  • DBMS / MySQL: You only need to know which command to use where and in which scenario (e.g. joins vs subqueries, window functions vs group by, when to index).
  • Operating Systems: Study strictly for MCQs; focus primarily on numericals (CPU scheduling wait/turnaround times, Banker's algorithm safe sequence, page faults).
  • Aptitude: First learn the core concepts through worked examples, then immediately dive into solving practice questions.

Rules for the 16-Day Sprint

01 — Don't binge lectures.
Use Striver to understand the concept, then code. The goal is problem-solving, not lecture completion.
02 — 15-minute rule.
For a new problem, think seriously for ~10–15 minutes before looking at a hint or approach.
03 — Never copy solutions.
If you look at the solution, close it and write the implementation yourself.
04 — Track failures.
A problem you couldn't solve is more valuable for revision than one you solved immediately.
05 — Pattern > Problem.
After every important problem, ask: "What pattern was this testing?"
06 — Coding gets priority.
If time runs short, reduce aptitude/CS time before reducing DSA practice.
07 — Don't chase 200 questions.
10 properly understood problems are more useful than 30 problems whose solutions you copied.
08 — Last 3 days are different.
Stop accumulating theory. Start simulating the actual placement environment.

DSA Pattern Recognition Cheat Sheet

If you see... Think...
Need fast lookup / frequency HashMap / Set
Sorted array + target Binary Search
Minimum / maximum possible value + feasibility Binary Search on Answer
Contiguous subarray / substring Sliding Window / Prefix Sum
Pair / triplet in sorted data Two Pointers
Next greater / smaller element Monotonic Stack
Tree shortest level-wise traversal BFS / Queue
Explore every path / component DFS
Prerequisites / dependency ordering Topological Sort
Repeated subproblems + optimal decisions Dynamic Programming
Top K / continuously smallest/largest Heap / Priority Queue
Maximum non-overlapping intervals Greedy + sort by end
